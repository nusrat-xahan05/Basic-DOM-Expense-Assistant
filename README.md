# 💰 DOM Expense Assistant - Practice Project

**DOM Expense Assistant** is a practice project focused on learning **DOM Manipulation** using JavaScript.  
The project allows users to input income, different expense types, and savings, then calculate the remaining balance.  
All calculations are stored and displayed in a **history tab** for reference.

## ✨ Features

- 🧾 Input fields for:
  - 💼 Income
  - 🧑‍💻 Software Expense
  - 🎓 Course Expense
  - 🌐 Internet Expense
  - 💸 Savings
- ✅ Input validation to prevent incorrect or empty values
- 🧮 Calculates total expenses, savings amount, and remaining balance
- 📜 Saves calculation results to a **history list**
- 📱 Design layout using **Tailwind CSS**

## 🛠 Technologies Used

- 📝 HTML5  
- 🎨 Tailwind CSS (for styling)  
- ⚙️ JavaScript DOM Manipulation
